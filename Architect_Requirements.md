Job description

Java Microservices Technical Architect role is typically a senior architecture and technology leadership position focused on designing and delivering large-scale distributed systems using Java and Microservices. Based on recent Publicis Sapient job postings, the key responsibilities and requirements include:

Key Responsibilities

    Design and architect large-scale, high-volume, low-latency, highly available distributed applications.
    Lead solution architecture from concept through implementation.
    Drive technical decisions, governance, and technology selection.
    Collaborate with clients, stakeholders, product teams, and engineering teams.
    Define microservices and event-driven architectures.
    Ensure enterprise-level security, compliance, and data protection.
    Mentor development teams and establish engineering best practices.
    Conduct architecture reviews, code reviews, and performance optimization. 

Required Technical Skills

Core Java

    Java 8+ (often Java 11/17/21 preferred)
    Concurrency and Multithreading
    Streams, Lambdas, Generics
    Blocking and Non-Blocking
    Design Patterns and OOP principles (SOLID, DRY) 

Microservices & Backend

    Spring Boot
    REST APIs
    Event-Driven Architecture
    Domain-Driven Architecture
    Kafka
    API Gateway patterns
    Distributed Systems Design 

Databases

    SQL Databases (Oracle, PostgreSQL, MySQL)
    NoSQL Databases (MongoDB, Cassandra, DynamoDB) 

Cloud & DevOps

    AWS
    Docker
    CI/CD Pipelines
    Git 

Testing & Performance

    JUnit 

Experience Expectations

    Typically 11+ years of software engineering experience.
    Experience delivering at least 2 large-scale projects from scratch (greenfield projects).
    Strong stakeholder management and client-facing skills.
    Ability to define architecture roadmaps and influence business decisions.
